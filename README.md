# Pivot

Pin a point on an image, swing a handle, and the picture turns around that point like a wheel of rings. Every band turns by its own amount, and turns stack on top of each other.

A [Maybe Machine](https://maybemachines.com) by [Ravi Popat](https://ravipopat.info).

Sample photo by Maria Lysenko on [Unsplash](https://unsplash.com/photos/75W3tzzFkZA).
